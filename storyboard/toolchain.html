How the video is made

The video is built as code-based motion graphics. Every scene is written as a small program that places your images, screenshots and vector graphics on a 1920 × 1080 canvas and animates them frame by frame. A renderer then turns the frames into an MP4. Because everything is defined in code, replacing a placeholder, correcting a value or adjusting timing only means editing a file and re-rendering. Nothing has to be re-animated by hand.

What you receive and how to edit it

Project structure

preview/
├─ public/                # your images (swap files here)
│  ├─ device_render.jpg
│  └─ website_location.jpg
├─ src/
│  ├─ Root.tsx            # video settings: size, fps, length
│  ├─ theme.ts            # colour palette, font, easing
│  ├─ components.tsx      # title pill, cursor, image crop
│  ├─ SceneDevice.tsx     # Scene 1: device introduction
│  └─ SceneLocation.tsx   # Scene 2: location acquisition
├─ out/                   # rendered MP4 files
└─ package.json

Each new scene (3–9) is added as its own Scene…tsx file, so every part of the video can be edited on its own.

Why code-based animation suits this project

  • Accurate: numbers and images come directly from your files, so no value is retyped or invented.
  • Easy revisions: placeholders (final interface, irradiance data, extra captures) can be swapped later without redoing the animation.
  • Consistent: one palette, font and motion style shared by all scenes.
  • Reproducible: the same source always renders the same video, and it can be kept under version control (Git).

Open, preview and render

  1. Install Node.js (version 18 or newer) from nodejs.org.
  2. Open a terminal in the preview folder and install the dependencies once: 
    npm install
  3. Open the live editor (a browser timeline you can scrub): 
    npm run studio
  4. Render the final MP4 into out/: 
    npm run render

Common edits

  • Replace an image: put the new file in public/ with the same name and re-render.
  • Change on-screen text: edit the text in the scene file (e.g. the title in SceneDevice.tsx).
  • Change colours: edit the palette in theme.ts; it updates everywhere.
  • Adjust timing: each animation is defined by frame numbers (30 frames = 1 second) in its scene file.
